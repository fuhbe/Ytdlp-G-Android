# Changelog

## 0.6.6

Official stable release of the device-approved Liquid Glass implementation.

- Preserves MP3/MP4 downloads, playlists, ZIP, persistent queue, pause/resume/cancel and destination selection.
- Keeps the elastic glass capsules, reflections, refraction and progressive icon illumination.
- Retains generous endpoint selection and diagonal dragging beyond a selector's visual height.
- Keeps Material touch flashes disabled only within the glass sliders.
- Presents the interface controls and public documentation in English.
- Sets the installed version to 0.6.6 and advances its Android version code to 70.
- Adds actual final-version captures for Home, MP3/MP4, quality selection, playlists, Downloads/Completed and Settings in both themes.
- Includes final APK/source checksums, signature information and reproducible verification records.

## 0.6.4

- Introduced the approved sliding glass navigation, refreshed wallpapers and light/dark appearance.
- Preserved the existing media and storage pipeline.

## 0.6.2

- Added independent playlist recovery, partial-success ZIP export and distinct media-processing stages.
- Added bounded retries, output reuse, supervised native processing and conservative transfer tuning.

Earlier releases and tags remain available in [GitHub Releases](https://github.com/fuhbe/Ytdlp-G-Android/releases).
