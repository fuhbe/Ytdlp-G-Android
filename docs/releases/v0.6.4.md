# Ytdlp-G 0.6.4 — Liquid Glass

A smoother glass interface for Ytdlp-G, with a draggable navigation capsule,
responsive highlights and new light/dark wallpapers. Download videos and playlists
as MP4, convert the best available audio to MP3, and manage your existing queue.

**Download `Ytdlp-G.apk` from Assets below. Android 8.0+ · ARM64.**

This is the exact APK approved by the project owner. Publication reuses the
verified Actions artifact without rebuilding or re-signing it.

## What's new

- One sliding navigation capsule follows horizontal drags with a damped spring.
- Releasing outside the dock or cancelling restores the current selection.
- Touch, keyboard and accessibility navigation retain the existing destinations.
- Interactive edge highlights, soft internal lighting and animated selection material.
- Supplied light/dark wallpapers with proportional cropping and bounded bitmap caching.
- Improved disabled-button contrast on light glass.

The download engine, available formats/quality choices, MP3/MP4 conversion,
playlists, ZIP export, folders, queue and background-processing behavior are preserved.
No new downloader setting or feature was introduced by this visual update.

## Material compatibility

Android 8–11 uses lightweight translucent material and highlights. Android 12/12L
adds real sampled blur. Android 13+ can also use AGSL edge refraction on supported
accelerated devices. Low-RAM devices, power saver and unsupported rendering use
the lightweight fallback. Backdrop remains at 1.0.3; minimum Android is unchanged.

## Upgrading

If you installed the approved 0.6.4 Actions APK, this release has the **same bytes
and signing certificate**. Published 0.6.2/0.6.3 APKs used different CI certificates,
so Android rejects an in-place update from those builds. Uninstalling removes
private queue/settings/partial files; finish/export needed work before considering
reinstallation. Previously exported media files remain in their destination.

Previous releases remain available.
