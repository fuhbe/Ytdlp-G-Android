## Ytdlp-G Android 0.3.0 beta 1

The glass interface now follows the original design: a compact link bar, video/audio tabs, one quality panel, files/ZIP controls, and a dedicated download screen with individual results.

- Bundle yt-dlp 2026.10.21 and its JavaScript solver; replace the previously installed extractor during upgrades.
- Keep Python, FFmpeg and QuickJS inside the APK.
- Analyze pasted links automatically, cache recent results, inspect playlist entries two at a time, and allow analysis cancellation.
- Limit network retries and waiting time; refresh a refused media stream once and show the source error if it still fails.
- Show actual audio codecs, bitrates and size estimates when supplied by the source.
- Save directly to Download/Ytdlp-G on Android 10+, or use a chosen folder.
- Validate ZIP contents and record an item as completed only after it has been saved.
- Keep all controls readable with explicit text colors and support English, Brazilian Portuguese and Spanish.

Download the APK below. This is a debug-signed beta; if Android reports a conflicting signature, uninstall the previous preview before installing it. Files already saved in Downloads are retained.

If a link fails, open Details and use Copy details when reporting the problem.
