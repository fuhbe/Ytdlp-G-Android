## Ytdlp-G Android v0.1.0 — Preview

This first Android preview has a compact acrylic blue interface and supports single videos and playlists, available video/audio choices, best-source MP3 conversion, regular-file output, and ZIP output. The interface is available in English, Brazilian Portuguese, and Spanish. On Android 13 and later, the app language can also be selected in system settings.

Download `Ytdlp-G-Android-v0.1.0.apk` below and open it on Android 8.0 or later. Python and FFmpeg are bundled; no separate installation is needed.

This is a debug-signed preview built by GitHub Actions. Android lint and translation checks passed. Android may warn about installing an APK from outside an app store. Please report any issues you find.
