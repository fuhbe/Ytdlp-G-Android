# Ytdlp-G 0.6.6-test3 — Liquid Glass

A compact video, music and playlist downloader with a responsive glass interface. Paste a link, choose MP3 or MP4, and save individual files or a playlist ZIP.

**Download `Ytdlp-G.apk` from Assets below. Android 8.0+ · ARM64.**

This release publishes the exact APK approved by the project owner after testing. If you already installed the 0.6.6-test3 APK from Actions run 40018985216, you already have this version. It has not been rebuilt or re-signed. The version retains its test identifier; stable 0.6.4 remains available unchanged.

## What's improved

- Glass capsules follow horizontal gestures across format, output, download-list and navigation selectors.
- Dragging to either edge selects the first or last option, including the control's inner margins and horizontal overshoot.
- Releasing the capsule keeps the selected destination while the spring settles.
- Standard Material touch flashes are disabled only inside the sliders. The glass reflections, progressive lighting and elastic response remain.
- The existing wallpapers, screen structure and download system are preserved.

MP3/MP4 downloads, playlists, ZIP export, pause/resume/cancel and destination folders retain their existing behavior. Python, yt-dlp, FFmpeg and the JavaScript runtime are bundled.

## Installation

The APK is for ARM64 Android devices. Allow installation from the browser or file manager when Android requests it. This APK uses the same signing key as the approved test3 build. Its key differs from earlier previews and 0.6.4, so those installations cannot be updated in place. Export needed files before uninstalling an older differently signed build; uninstalling clears private settings, queued jobs and partial files.
