## What's included

- Device-approved glass navigation and format/output selectors, with elastic deformation, reflections, refraction and progressive icon illumination on supported rendering paths.
- Generous endpoint selection and natural diagonal dragging outside the slider, while preserving normal vertical scrolling and genuine cancellation.
- Best-source high-quality VBR MP3, MP4 at available resolutions up to 2160p, playlist selection and multi-item ZIP export.
- Persistent queue, pause/resume/cancel, destination folders, per-item results and eligible retries.
- English presentation labels and light/dark appearance.

The existing engine, yt-dlp, FFmpeg, playlists, ZIP, queue, workers, services, storage and optical/gesture implementation are preserved. The installed version is **0.6.6**, version code **70**.

## Install

Download **Ytdlp-G.apk** below and allow installation from your browser or file manager if Android asks. Python, yt-dlp, FFmpeg, FFprobe and QuickJS are bundled. No separate Python installation is required.

Paste a link, tap **Analyze link**, choose format, quality and destination, then **Download**. ZIP is offered for two or more selected playlist entries. Android 10+ defaults to `Downloads/Ytdlp-G`; Android 8/9 users should choose a folder first.

MP4 conversion can take longer than downloading and cannot improve source quality. Restricted or unavailable items remain subject to source permissions and availability. Some preserved runtime messages can retain their original language.

Android requires matching certificates for in-place updates. The actual signing mode and certificate are recorded in `release-info.json`. Before uninstalling a differently signed older installation, finish/export needed files: uninstalling clears private settings, queue and partial files. Exported destination files remain.
