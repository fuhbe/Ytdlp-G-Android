# Ytdlp-G 0.6.6

Official stable Android release. Install **Ytdlp-G.apk** on ARM64 Android 8.0+.

The device-approved download and Liquid Glass implementation is preserved. The installed version is 0.6.6, with English presentation labels. Python, yt-dlp, FFmpeg, FFprobe and QuickJS are bundled.

`SHA256SUMS.txt` records APK and corresponding-source digests. `VERIFIED.json` identifies the actual compiled source, APK certificate, signing mode, complete automated results and genuine application captures. GPL-3.0-only, with bundled dependency notices and corresponding source in `Ytdlp-G-source.zip`.

Android requires the same signing certificate for in-place updates. If a differently signed older installation must be removed, finish/export needed files first: uninstalling clears private settings, jobs and partial files. Already exported files remain in their destination folder.

The final release and complete integrity files are published at https://github.com/fuhbe/Ytdlp-G-Android/releases/tag/v0.6.6 .
