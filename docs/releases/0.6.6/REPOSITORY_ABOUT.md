# Repository About description

The official stable release and English README are published. Updating GitHub's separate repository About field was attempted with the available publishing credentials, but GitHub returned **HTTP 403**. That credential can publish release assets and source, but cannot edit this administration metadata.

An owner/admin can finish this field from the repository homepage: open the gear beside **About**, paste the description below and save. This does not require rebuilding or changing the app.

> Download YouTube videos, music and playlists as MP3, MP4 or ZIP. Android app with an interactive Liquid Glass interface.

The release automation can also apply it when an owner-provided `REPO_ADMIN_TOKEN` with the required repository administration access is configured. No token or private signing key should be pasted into public files.
