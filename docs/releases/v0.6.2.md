# Ytdlp-G 0.6.2 - Liquid Glass for Android

<img src="https://raw.githubusercontent.com/fuhbe/Ytdlp-G-Android/main/docs/branding/icon.png" width="80" alt="Ytdlp-G app icon">

A compact YouTube video, music and playlist downloader with a blue Liquid Glass interface. **Android 8.0+ · ARM64 · GPL-3.0-only.**

## Download and install

Download **Ytdlp-G.apk** below. Python, yt-dlp, FFmpeg, FFprobe and the JavaScript runtime are included. No separate Python installation is needed. `Ytdlp-G-source.zip` contains corresponding source, not the installer.

On Android 10+, the default output folder is `Downloads/Ytdlp-G`. Android 8/9 users should choose a destination folder first. The app interface in this release is Brazilian Portuguese; these release notes are English.

## Features

- Single videos, playlists and multiple YouTube links.
- Best-source MP3 audio and MP4 video at available resolutions, up to 2160p.
- Individual files or a playlist ZIP, with selection before download.
- Persistent jobs, pause/resume/cancel, light/dark themes and a folder picker.
- Per-item results and retrying eligible failures while retaining completed files.

## Improvements in this version

- An unavailable playlist entry no longer stops the remaining entries.
- A partially successful playlist can still produce a verified, nonempty ZIP.
- Downloading, MP4 processing, validation and saving have distinct progress stages.
- Compatible H.264/AAC streams are copied/remuxed; incompatible streams are converted only when needed.
- Native transfers use conservative resource-based concurrency and bounded retries.
- Validated output can be reused after an export failure; a guarded process reader fixes a reproduced callback/pipe deadlock.

MP4 conversion uses the phone's CPU and can be slower than downloading, especially at high resolutions. It cannot improve source quality. Restricted/unavailable videos and server limits remain subject to the source service.

## Verification

- **57 automated tests passed**, plus real HTTP/HLS/DASH and MP3/MP4 generated-media checks.
- A 16-item controlled playlist with failures at positions 5 and 12 produced fourteen real MP3 files and a fourteen-entry ZIP.
- Final APK signature, bundled runtimes, ZIP CRCs, reflective ZIP constructors and archive/R8 regression controls passed.
- Three paired host benchmark repetitions per case. MP4 conversion median was 7.7% lower in this fixture; other before/after changes ranged from -0.2% to +0.3%. Four versus one HLS fragment reduced total time by 18.9% with deliberately controlled segment latency. These are host fixture measurements, not phone/Internet speed promises.
- The user reported a successful video download/conversion retry on a Redmi 10 Prime with Android 12. Four additional native instrumentation scenarios are provided separately for device diagnostics; a compiled test package does not establish a passing device run.

## Existing installations

This release contains **the exact APK already published by successful Actions run 39878394553**. If you installed that 0.6.2 build, you already have this version. It has not been rebuilt or re-signed for this release.

Its certificate differs from 0.6.1. Android will refuse an in-place update from that preview. Finish/export what you need before uninstalling: uninstall removes the private queue, settings and partial files. Already exported files in Downloads or the selected external folder remain.
