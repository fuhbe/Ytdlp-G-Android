# Ytdlp-G 0.6.6-test2

Extract and install `Ytdlp-G.apk` (ARM64, Android 8+). This is a visual test build
on an isolated branch; stable v0.6.4 remains unchanged. See `VISUAL_REPORT.md`,
`VERIFIED.json`, `screenshots/` and `DEVICE_CHECK.md` for evidence and limitations.
GPU appearance/frame rate still need phone testing. The matching instrumentation
APK is a separate artifact from the same run.

CI uses a development signing key which can differ from your installed version.
Android may reject an in-place update. Keep the working app and preserve your
data; do not uninstall a copy with queue/history you cannot afford to lose.
The unchanged package ID prevents side-by-side installation.

The source archive and all required licenses accompany the APK.
