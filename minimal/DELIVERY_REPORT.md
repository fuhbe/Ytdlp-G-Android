# Ytdlp-G 0.6.2 — delivery status

Independent playlist outcomes, partial-success ZIP, supervised real MP4
processing and conservative automatic transfer tuning are implemented. See
[TURBO_REPORT.md](TURBO_REPORT.md) for confirmed defects, changed files, regression
coverage, performance scope and remaining phone acceptance.

This source snapshot precedes verification of the new GitHub build. It does not
claim that a new APK has already been published. The delivery record is updated
in a documentation-only commit after the exact artifacts are downloaded and
checked. Use only a completed successful **Ytdlp-G Minimal Liquid Glass** run for
this version. The main artifact is **Ytdlp-G-Android-Minimal**; the APK inside is
**Ytdlp-G.apk**. **Minimal-verification** contains actual test/mapping reports;
**Android-device-tests** contains the matching instrumented test APK, not a test
execution result.

The CI test signing certificate may differ from the previous APK. Do not
uninstall an installation holding needed private partials/queue data. Read the
signing/data guidance in TURBO_REPORT.md first. No live YouTube or Redmi success
is claimed without the corresponding device evidence.
